## Version Taxonomy

A software version taxonomy is a structured classification system used to name, categorize, and order different states or releases of a computer program. It defines the rules and labels—such as major, minor, patch, or alpha and beta tags—that tell users how code changes, grows, and relates to past iterations.

### Version Numbering

Versions are maintained using Semantic Versioning (MAJOR.MINOR.PATCH) and a predictable Release Lifecycle that transitions code lines through Current, Long-Term Support (LTS), and End-of-Life (EOL) phases to balance rapid innovation with enterprise stability.
